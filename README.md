# 🏏 Finger Cricket Pro

An interactive, highly engaging web-based "Finger Cricket" (Hand Cricket) game built with React. Play against a smart AI opponent, track your scores in real-time, and relive the nostalgia of this classic childhood game with a modern digital twist!

## 🌟 Features
- **Interactive Toss System:** Call Heads or Tails to decide who bats or bowls first.
- **Smart AI Logic:** Dynamic opponent gameplay powered by randomized algorithms and AI integration.
- **Real-time Score Tracking:** Live, instant updates of runs, wickets, and match status.
- **Strict Security:** API keys and sensitive data are safely isolated using environment variables (`.env.local`).
- **Responsive Design:** A clean, optimized UI that works seamlessly across desktop and mobile browsers.

## 🛠️ Tech Stack
- **Frontend Core:** React.js, TypeScript, Vite
- **Web Technologies:** HTML5, Modern CSS3
- **Deployment & Hosting:** Netlify (Automated CI/CD Pipeline)
- **Version Control:** Git & GitHub

## 🚀 Getting Started

Follow these instructions to set up and run the project locally on your machine.

### 1. Clone the repository
```bash
git clone [https://github.com/AnurajPatil1204/finger-cricket-pro.git](https://github.com/AnurajPatil1204/finger-cricket-pro.git)
cd finger-cricket-pro

🎮 How to Play
1.The Toss: Choose Heads or Tails. The winner gets to choose whether to Bat or Bowl.

2.Gameplay: In each delivery, both you and the AI simultaneously choose a number between 1 and 6.

3.Batting: If your number does not match the AI's number, your chosen number is added to your total score.

4.Wicket (OUT): If your number matches the AI's number exactly, the batter is declared OUT!

5.Winning: Successfully chase down the target score, or defend your total by getting the AI out.
